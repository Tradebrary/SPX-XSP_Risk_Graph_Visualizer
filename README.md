# SPX-XSP Options Visualizer

Visualize SPX options positions hedged with XSP options — shape a risk graph
you're comfortable holding to expiration. Plot combined P/L at expiration,
drag strikes interactively, compute POP and expected value, stream live data
from Tastytrade or Interactive Brokers, and optimize strategy parameters.

**Purchase a license on Whop** — your license key is shown on your Whop
membership page after purchase. One key activates on up to **two computers**
you own (e.g., desktop + laptop).

## Download & Install

1. Click the green **Code** button (top right of this page) → **Download ZIP**.
2. Extract the ZIP and read **`Installation_Instructions.pdf`**.
3. Run **`OptionsRiskGraphSetup-<version>.exe`** and follow the steps.
4. On first launch, activate with the license key from your Whop membership page.

> Windows may show a SmartScreen notice for new software — click
> **More info → Run anyway**. See the Installation Instructions for details.

Windows 10/11 (64-bit), 4 GB RAM (8 GB recommended), 1600×900 display or
larger. Internet required for activation and live broker data.
